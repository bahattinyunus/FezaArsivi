## 🤝 Katkıda Bulunma

Bu arşiv topluluk katkılarıyla büyümektedir. Katkıda bulunmak için:

1. Bu repoyu fork'layın.
2. Yeni bir dal (branch) oluşturun (`git checkout -b yeni-ozellik`).
3. Değişikliklerinizi yapın ve commit'leyin (`git commit -m 'Yeni kaynak eklendi'`).
4. Dalınızı push'layın (`git push origin yeni-ozellik`).
5. Bir Pull Request oluşturun.

Lütfen katkıda bulunmadan önce `CONTRIBUTING.md` ve `CODE_OF_CONDUCT.md` dosyalarını inceleyin.
